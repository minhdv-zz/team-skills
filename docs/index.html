Cài plugin Paseo (làm một lần)

Bấm copy, rồi dán vào một chat Claude trong Paseo. Claude sẽ tự cài giúp bạn.

Plugin chạy không có sandbox. Dán vào chat nghĩa là bạn đồng ý cài.
Cách khác: tự làm tay

Paseo → Settings → Plugins, dán nguồn này vào ô Plugin source, bấm Install plugin:


      
      
Hoặc chạy lệnh: 

      
Đã cài rồi mà nút không bấm được? Cập nhật: paseo plugin update team-skills

Đóng góp skill hoặc addon của bạn

      
Cần tài khoản GitHub. Chủ repo duyệt xong mới hiện cho cả team.

      
    
        
  1. 
          Cập nhật plugin Paseo (một lần)
          
    
          
    Hoặc chạy lệnh paseo plugin update team-skills
    
        
    2. 
        
  2. 
          Điền tên hoặc đường dẫn, rồi copy lời nhờ
          
    
            
            
          
    
          
          
    Dán vào một chat mới trong Paseo (mở trong thư mục dự án nếu skill nằm trong dự án).
    
        
    3. 
        
  3. 
          Làm theo Claude
          
    Trả lời câu hỏi, đăng nhập GitHub khi trang được mở, rồi nhận link Pull Request.
    
        
    4. 
      

      
Cần có: tên tác giả trong skill/addon · addon phải miễn phí và được chia sẻ lại · không chứa khóa, token, mật khẩu. Hệ thống tự quét.

    


    

      Không dùng Paseo? Gửi thủ công trên GitHub
      

        

          
Skill

          
          

            1. Tạo SKILL.md trên GitHub
            2. Thêm file kèm theo
          

          
Bước 1 mở trang tạo file có sẵn mẫu, chỉnh rồi bấm Propose new file. Bước 2 chỉ cần khi skill có thêm file, làm sau khi bước 1 được gộp.

        

        

          
Addon Blender

          
          

            Tải addon lên GitHub
          

          
Kéo thả nguyên thư mục addon vào trang vừa mở rồi bấm Propose changes.

        

      

      
Chưa có quyền ghi vào repo thì GitHub tự tạo bản sao cho bạn. Hướng dẫn đầy đủ: CONTRIBUTING.md

    

  

  

  






  

    

    

      
Cách nhanh: nhờ Claude làm giúp

      

      
      
Dán vào một cuộc chat Claude trong Paseo. Claude cài plugin (nếu chưa có) rồi cài luôn mục này. Plugin chạy không có sandbox, dán vào chat nghĩa là bạn đồng ý cài.

Cần bạn bấm “Cho phép”

    
Trình duyệt đang hỏi bạn ở góc trên bên trái màn hình:

    
“minhdv-zz.github.io muốn truy nhập các ứng dụng và dịch vụ khác trên thiết bị này”

    
Bắt buộc bấm “Cho phép” thì trang mới nói chuyện được với plugin Paseo trên máy bạn để cài, gỡ và cập nhật skill, addon tự động. Bấm Chặn thì các nút Cài và Gỡ cài sẽ không chạy.

    
Hộp thoại không hiện? Tiếp tục không cần cho phép (chỉ dùng được lệnh copy thủ công).
