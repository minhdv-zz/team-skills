Chưa kết nối Paseo? Cài plugin một lần

Mở Paseo, vào Settings → Plugins, dán nguồn plugin vào ô Plugin source rồi bấm Install plugin:


    
    
Hoặc dùng dòng lệnh: 

    
Sau khi plugin chạy, tải lại trang này. Chấm tròn ở trên sẽ chuyển sang xanh.

    
Đã cài plugin từ trước mà nút Cài addon không bấm được? Plugin được ghim theo phiên bản, hãy cập nhật: paseo plugin update team-skills

  


  

  

  

    

      
Đóng góp skill hoặc addon của bạn

      
Gửi lên kho chung cho cả team dùng. Chủ repo duyệt rồi mới hiện. Cần một tài khoản GitHub.


      
    
        
  1. 
          Cập nhật plugin Paseo (làm một lần)
          
    paseo plugin update team-skills
    
          
        
    2. 
        
  2. 
          Mở một cuộc chat mới trong Paseo và nhắn Claude
          
    Hãy đóng góp skill tên-skill-của-bạn lên Team Skills
    
          
          
    Hãy đóng góp addon Blender tên-addon-của-bạn lên Team Skills
    
          
        
    3. 
        
  3. 
          Claude kiểm tra giúp bạn, tự sửa lỗi nhỏ (ví dụ thêm tên tác giả) và hỏi bạn có đồng ý công khai không. Chỉ cần trả lời.
        
    4. 
        
  4. 
          Đăng nhập GitHub khi được mở trang: nhập mã hiện ra rồi bấm Authorize. Xong Claude gửi cho bạn link Pull Request. Việc còn lại là chờ chủ repo duyệt.

Trước khi gửi, kiểm tra nhanh

      
    
        
  • Có tên tác giả: dòng author: trong SKILL.md, hoặc author trong bl_info của addon.
    • 
        
  • Addon phải miễn phí và được phép chia sẻ lại, kèm file giấy phép. Addon trả phí thì không đưa lên.
    • 
        
  • Không có khóa, token, mật khẩu hay file .exe/.dll trong skill. Hệ thống tự quét và từ chối.
    • 
      

    


    

      Không dùng Paseo? Gửi thủ công trên GitHub
      

        

          
Skill

          
          

            1. Tạo SKILL.md trên GitHub
            2. Thêm file kèm theo
